# Smart Hospital Emergency Triage Desk

## About the Project
A beginner-friendly Java application demonstrating Object-Oriented Programming concepts through a hospital patient registration system.

## Features
- Register multiple patients.
- Enter patient ID, name and medical condition.
- Display all registered patients.
- Display total patient count.
- Assign patients to a doctor.

## Java Concepts Used
1. Classes and Objects
2. Methods
3. Constructors
4. Access Specifiers
5. Overloading
6. Inheritance
7. Interfaces
8. Abstract Methods
9. Packages

## Additional Java Features
- Scanner
- ArrayList
- While loop
- Conditional statements

## Technologies
- Java
- Notepad
- Command Prompt

## How to Run
Compile:
`javac -d ..\..\out *.java`

Run:
`java -cp ..\..\out hospital.Main`
